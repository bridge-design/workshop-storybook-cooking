# Components/Alert

## Props

See Storybook controls for interactive prop documentation.

## Stories

### Info

Info variant is used for informational messages. Use cases: - General information - Tips and hints - System updates - Feature announcements

```tsx
<Alert variant="Info" icon link dismissible text="Emphasized description." linkLabel="Link" />
```

### Warning

Warning variant is used for cautionary messages. Use cases: - Important notices - Upcoming changes - Action required warnings - Deprecation notices

```tsx
<Alert variant="Warning" icon link dismissible text="Emphasized description." linkLabel="Link" />
```

### Success

Success variant is used for positive confirmation messages. Use cases: - Successful operations - Completion confirmations - Achievement notifications - Positive feedback

```tsx
<Alert variant="Success" icon link dismissible text="Emphasized description." linkLabel="Link" />
```

### Danger

Danger variant is used for critical error messages. Use cases: - Error notifications - Critical warnings - System failures - Security alerts

```tsx
<Alert variant="Danger" icon link dismissible text="Emphasized description." linkLabel="Link" />
```

### WithoutIcon

Alert without icon. Use cases: - Minimal design requirements - Space-constrained layouts - When icon is redundant

```tsx
<Alert variant="Info" icon={false} link dismissible text="Emphasized description." linkLabel="Link" />
```

### WithoutLink

Alert without link. Use cases: - Simple notifications - When no action is needed - Standalone messages

```tsx
<Alert variant="Info" icon link={false} dismissible text="Emphasized description." linkLabel="Link" />
```

### NonDismissible

Non-dismissible alert. Use cases: - Critical system messages - Required acknowledgments - Persistent notifications

```tsx
<Alert variant="Info" icon link dismissible={false} text="Emphasized description." linkLabel="Link" />
```

### CustomContent

Alert with custom content using children prop. When children are provided, text and linkLabel are ignored.

```tsx
<Alert variant="Info" icon link dismissible text="Emphasized description." linkLabel="Link">
<>
  <span>Custom alert message with <strong>bold text</strong>.</span>
  <a href="#" onClick={(e) => e.preventDefault()}>Learn more</a>
  </>
</Alert>
```

### AllVariants

All alert variants displayed together.

```tsx
<div style={{ display: 'flex', flexDirection: 'column', gap: '8px' }}>
<Alert variant="Info" text="This is an info alert" />
<Alert variant="Warning" text="This is a warning alert" />
<Alert variant="Success" text="This is a success alert" />
<Alert variant="Danger" text="This is a danger alert" />
</div>
```
