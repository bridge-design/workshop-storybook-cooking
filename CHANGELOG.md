# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

### Bug Fixes

* Fixed Accordion component indicator alignment
* Improved Alert component accessibility attributes
* Fixed Button disabled state styling

## [1.17.2] - 2024-01-15

### Bug Fixes

* Fixed Table component responsive behavior
* Improved Tabs component keyboard navigation

## [1.17.1] - 2024-01-10

### Bug Fixes

* Fixed Avatar component image loading
* Improved Badge component status display

## [1.17.0] - 2024-01-08

### Features

* Added new Header component with Logo and Menubar integration
* Enhanced Layout component with improved spacing options
* Added new Tabs component with keyboard navigation support

## [1.16.0] - 2023-12-20

### Features

* Added Accordion component with expand/collapse functionality
* Enhanced Alert component with new variants (Info, Warning, Success, Danger)
* Improved Button component with additional size variants

### Bug Fixes

* Fixed Table component cell alignment
* Improved Menubar component active state styling

## [1.15.0] - 2023-12-10

### Features

* Added Avatar component with size variants
* Added Badge component with status indicators
* Enhanced Alert component with dismissible functionality

## [1.14.0] - 2023-11-25

### Features

* Initial release of core components
* Added Button component with multiple variants
* Added Table component with header and body sections
* Added Layout component for page structure
* Added Logo component with variant support
* Added Menubar component with navigation items
